# DocketLens demo script — target 2:10

Use the real FTC workflow in `DEMO_DATA.md`. Never show the API key.

## 0:00–0:22 — The product

**Show:** `FTC-2023-0033`, 1,163 live comments, source badge, and `8 site tools ready`.

**Say:** “Federal rulemakings can receive thousands of public comments. DocketLens is a shared research workspace where an analyst and an agent can investigate those records without losing the original evidence.”

## 0:22–1:12 — Why WebMCP

**Show:** The agent searches `cancel` on page 1 and page 2, tags visible records, inspects `FTC-2023-0033-1056` and `FTC-2023-0033-1136`, then compares them.

**Say:** “The agent uses eight structured WebMCP tools—not visual guesses. Search, pagination, inspection, tagging, and comparison update the same page I can see. Every record comes live from Regulations.gov, and every source link remains available.”

## 1:12–1:42 — Evidence safeguards

**Show:** Two exact excerpts appear as pending pins. The agent prepares the brief. Copy and Download remain disabled.

**Say:** “A pin is accepted only when its quote exactly exists in the fetched comment and belongs to the active docket. Agent evidence starts pending. It can be previewed, but it cannot be exported until a person verifies it.”

## 1:42–2:00 — Human judgment

**Show:** Manually click both **Verify** buttons, then preview the brief.

**Say:** “The human checks the wording and owns the conclusion. After verification, the cited Markdown brief becomes exportable, with exact excerpts, comment IDs, source links, and review status.”

## 2:00–2:10 — Boundary and value

**Show:** Activity trail and final card.

**Say:** “DocketLens never files a government comment. WebMCP makes the website a reliable collaboration surface: the agent accelerates research, while the analyst can see, verify, and audit every step.”
